# Implementation Plan

1. Add `modernc.org/sqlite` dependency and set up `catalog/fbc/internal/` package with SQLite schema creation. Raw table names derive from FBC schema strings (replace `.` with `_`, prefix `raw_`): `raw_olm_package`, `raw_olm_channel`, `raw_olm_channel_entry`, `raw_olm_bundle`. Normalized tables: `graphs` (self-referential via nullable `parent_id`), `graph_bundles`, `successors`.
2. Define the `PackageSchemaHandler` interface in `catalog/fbc/internal/` and a registry for handlers keyed by package schema string.
3. Research and decide on SQLite transaction strategy for concurrent ingest. Key questions: (a) Can a single long-running transaction be shared across goroutines, or does each goroutine need its own? (b) What are the performance implications of autocommit-per-insert vs. batched transactions vs. a single wrapping transaction? (c) Does WAL mode change the answer? (d) What's the right approach for `modernc.org/sqlite` specifically? Document findings and implement the chosen strategy.
4. Implement the ingest phase in `catalog/fbc/internal/`: walk `declcfg.Meta` blobs via `WalkMetasFS` with `WithConcurrency(runtime.NumCPU())`, unmarshal each into its typed form (`declcfg.Package`, `declcfg.Channel`, `declcfg.Bundle`), extract minimal fields, and insert into raw tables. Parse bundle versions from the `olm.package` property. Use the transaction strategy from step 3.
5. Implement the `olm.package` handler: validate semantic constraints against the raw tables, populate normalized tables (`graphs`, `graph_bundles`), and compute successor edges from `replaces`, `skips`, and `skipRange`.
6. Implement the normalization dispatch in `catalog/fbc/internal/`: iterate over `raw_packages`, look up the handler for each package's schema, call `Normalize`.
7. Implement `catalogv1.Catalog`, `catalogv1.CompositeUpdateGraph`, and `catalogv1.UpdateGraph` query types in `catalog/fbc/internal/` backed by normalized SQLite table reads. All bundle values are `bundlev1.NameVersionRelease`.
8. Implement the public `catalog/fbc/` package: `Catalog` struct, `FromFS` constructor (wires together ingest, normalize, query), and `Close` method.
9. Write tests: valid FBC loading, query correctness (packages, channels, bundles, successors at both levels), error cases (malformed data, semantic violations), handler extensibility, and Close cleanup.
